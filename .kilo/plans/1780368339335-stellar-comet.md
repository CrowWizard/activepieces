## 步骤 5：通过 API 创建 Flow（3 步 AI 商品图流水线）

### 5.1 创建空壳 Flow

```bash
FLOW=$(curl -s -X POST "http://localhost:3000/v1/flows?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"displayName":"AI Product Image Pipeline"}')

FLOW_ID=$(echo $FLOW | jq -r '.id')
echo "Flow ID: $FLOW_ID"
```

### 5.2 设置 Webhook 触发器

```bash
curl -s -X POST "http://localhost:3000/v1/flows/$FLOW_ID?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "UPDATE_TRIGGER",
    "request": {
      "type": "PIECE_TRIGGER",
      "name": "trigger",
      "settings": {
        "pieceName": "@activepieces/piece-webhook",
        "pieceVersion": "0.0.1",
        "triggerName": "catch_webhook",
        "input": {}
      }
    }
  }'
```

### 5.3 添加 Step 1: Remove Background

```bash
curl -s -X POST "http://localhost:3000/v1/flows/$FLOW_ID?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "ADD_ACTION",
    "request": {
      "action": {
        "type": "PIECE",
        "name": "remove_background",
        "settings": {
          "pieceName": "@activepieces/piece-tongyi",
          "pieceVersion": "0.0.1",
          "actionName": "removeBackground",
          "input": {
            "imageFile": "{{trigger.body.imageFile}}",
            "filename": "transparent_product"
          }
        }
      },
      "parentStep": "trigger"
    }
  }'
```

### 5.4 添加 Step 2: Generate Background

```bash
curl -s -X POST "http://localhost:3000/v1/flows/$FLOW_ID?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "ADD_ACTION",
    "request": {
      "action": {
        "type": "PIECE",
        "name": "generate_background",
        "settings": {
          "pieceName": "@activepieces/piece-tongyi",
          "pieceVersion": "0.0.1",
          "actionName": "generateBackground",
          "input": {
            "imageFile": "{{remove_background.fileName}}",
            "backgroundPrompt": "{{trigger.body.backgroundPrompt}}",
            "filename": "bg_generated"
          }
        }
      },
      "parentStep": "remove_background"
    }
  }'
```

### 5.5 添加 Step 3: Image Pro Edit

```bash
curl -s -X POST "http://localhost:3000/v1/flows/$FLOW_ID?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "ADD_ACTION",
    "request": {
      "action": {
        "type": "PIECE",
        "name": "image_pro_edit",
        "settings": {
          "pieceName": "@activepieces/piece-tongyi",
          "pieceVersion": "0.0.1",
          "actionName": "imageProEdit",
          "input": {
            "imageFile": "{{generate_background.fileName}}",
            "editPrompt": "{{trigger.body.editPrompt}}",
            "filename": "final_output"
          }
        }
      },
      "parentStep": "generate_background"
    }
  }'
```

### 5.6 发布 Flow

```bash
curl -s -X POST "http://localhost:3000/v1/flows/$FLOW_ID?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "LOCK_AND_PUBLISH"}'
```


**成功标志**：
- `status` = `"ENABLED"`
- `publishedVersionId` 不为 null

### 6.2 在 UI 中查看

打开 `http://localhost:8080` → Flows → "AI Product Image Pipeline"，确认：
- 触发器是 Webhook
- 3 个步骤依次连接
- 状态为 Published/Enabled

### 6.3 测试运行（通过 Webhook 触发）

```bash

  -H "Content-Type: application/json" \
  -d '{
    "imageFile": "<base64-encoded-test-image>",
    "backgroundPrompt": "专业摄影棚，白色大理石台面，柔和灯光",
    "editPrompt": "增强细节，提升清晰度"
  }'
```

### 6.4 查看运行结果

```bash
# 列出 Flow 的运行记录
curl -s "http://localhost:3000/v1/flow-runs?projectId=$PROJECT_ID&flowId=$FLOW_ID&limit=5" \
  -H "Authorization: Bearer $TOKEN" | jq '.data[] | {
    id: .id,
    status: .status,
    startTime: .startTime,
    endTime: .endTime
  }'

# 查看某次运行的详细结果
RUN_ID="<run-id>"
curl -s "http://localhost:3000/v1/flow-runs/$RUN_ID?projectId=$PROJECT_ID" \
  -H "Authorization: Bearer $TOKEN" | jq '{
    status: .status,
    steps: .steps
  }'
```

**运行状态说明**：
- `RUNNING` — 正在执行
- `SUCCEEDED` — 成功完成
- `FAILED` — 失败（查看 `steps` 中 status=FAILED 的步骤的 errorMessage）
- `PAUSED` — 等待中

## 注意事项

1. **DashScope 模型名需确认**：`wanx-segmentation-matting` 和 `/api/v1/services/aigc/image-segmentation/generation` 是根据 DashScope API 命名惯例推测的，实际部署前需在阿里云百炼控制台确认可用的分割模型名和 API 路径。

2. **文件传递格式**：tongyi action 使用 `Property.File` 接收 base64 图片。Webhook trigger 的 `trigger.body.imageFile` 是原始 JSON 字符串，而 `Property.File` 期望的是含 `.base64` 属性的文件对象。如果步骤间传递有格式问题，可能需要在 Flow 中加一个 Code step 做格式转换。

3. **超时**：DashScope 异步 API 轮询最长约 2 分钟，3 步流程总计可能需要 5-10 分钟。`AP_FLOW_TIMEOUT_SECONDS=600` (10 分钟) 应够用，但同步 Webhook 调用可能超时。建议外部应用使用异步调用 + 轮询结果。

4. **Connection 绑定**：通过 API 创建 Flow 时，每个 action 的 `settings` 中需要包含 `connectionId`（通过 UI 创建时会自动绑定当前选择的 connection）。如果 API 创建后 connection 未绑定，需要通过 `UPDATE_ACTION` 操作补充。
