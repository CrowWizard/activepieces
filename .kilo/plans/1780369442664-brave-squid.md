# 实现计划：AI 商品图生成流程 — 新增 Remove Background Action

## 来源

基于 `.kilo/plans/1780368339335-stellar-comet.md` 的完整方案，聚焦可立即执行的代码变更。

## 关键发现

1. **DashScope 图像分割 API 未被 Python SDK 覆盖**：SDK 中无 `image_segmentation` 模块，但 DashScope REST API 支持该能力。模型名 `wanx-segmentation-matting` 和路径 `/api/v1/services/aigc/image-segmentation/generation` 是根据 DashScope 命名惯例推测的，**部署前需在百炼控制台确认**。
2. **`dashScopeClient` 完全可复用**：`client.ts` 的 `submitAndWait` + `downloadAsBuffer` 模式与现有 `generate-background.ts` 和 `image-pro-edit.ts` 完全一致。
3. **`Property.File` 步骤间传递问题**：当前 action 使用 `Property.File`（返回 `{ base64, ... }`），步骤间输出是 `files.write` 返回的 URL 字符串。Flow 中需要确保格式匹配——这是后续 Flow 创建时的问题，不影响本次 action 代码实现。

## 实施步骤

### Step 1：新增 `remove-background.ts`

**文件**：`packages/pieces/community/tongyi/src/lib/actions/remove-background.ts`

创建新 action，模式与 `generate-background.ts` 完全一致：
- `auth: tongyiAuth`
- `name: 'removeBackground'`
- `displayName: 'Remove Background'`
- `description: 'Remove image background and produce a transparent PNG using AI segmentation'`
- Props：`imageFile`（Property.File）、`filename`（Property.ShortText）
- Run：`dashScopeClient.submitAndWait` → `downloadAsBuffer` → `files.write` → return `{ fileName, url }`
- 常量：`MODEL = 'wanx-segmentation-matting'`，`SUBMIT_PATH = '/api/v1/services/aigc/image-segmentation/generation'`
- Input 构造：`{ image_url: 'data:image/png;base64,...' }`
- Parameters：`{ output_type: 'transparent' }`

### Step 2：修改 `index.ts` 注册新 action

**文件**：`packages/pieces/community/tongyi/src/index.ts`

- 添加 import：`import { removeBackground } from './lib/actions/remove-background';`
- 修改 actions 数组：`actions: [removeBackground, generateBackground, imageProEdit]`

### Step 3：构建验证

在 `packages/pieces/community/tongyi` 目录下执行 `npm run build`，确认 TypeScript 编译无错误。

## 不在本次范围内
